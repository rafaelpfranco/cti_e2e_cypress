# Evidencias

## Screenshots

Screenshots automaticos de falha ficam em:

```txt
cypress/screenshots
```

## Videos

Videos das execucoes headless ficam em:

```txt
cypress/videos
```

## Relatorios

Relatorios do `cypress-mochawesome-reporter` ficam em:

```txt
cypress/reports
```

## Downloads

Arquivos baixados durante os testes ficam em:

```txt
cypress/downloads
```

## PDFs Gerados

PDFs de termos e relatorios devem ser validados a partir de:

```txt
cypress/downloads
```

A validacao final do nome e conteudo dos PDFs deve ser implementada depois de confirmar o comportamento real de download do sistema.
